# Tarea 10 — solución inicial

Promedio con NULL - BDD

```sql
WITH muestra AS (
    SELECT
    FROM (values
        (1000::numeric),
        (0::numeric),
        (0::numeric,
        (NULL::numeric)
    ) AS v(valor)
)
SELECT
    AVG(valor) AS promedio_sin_coalesce
    COUNT(valor) AS denominador 3
FROM muestra;

WITH muestra AS (
    SELECT
    FROM (values)
        (1000::numeric),
        (0::numeric)
        (0::numeric)
        (NULL::numeric)
    ) AS v(valor)
)
```
Nota: Se conserva el segundo bloque incompleto y la anotación "denominador 3". El primer valor se lee como 1000 en ambos bloques; la cifra manuscrita es poco clara.
